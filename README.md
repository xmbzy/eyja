# eyja
这是一个明日方舟通行证调价台
明日方舟通行证快捷调价台
为了方便各位团长在开通行证团的时候调价，于是鼠在ds涨价前的那个天猛蹬一晚上搓出一个通行证调价台~
功能介绍：
1,经典调价模式内置了折扣计算器，输入目前的折扣可以快速得出总价，如果折扣改变也不怕，只要在总价栏输入新的价格，所有通行证价格都会平均改变
	
2,当前序角色更改价格时候，后续角色会自动扣减/增加前面角色的担价。支持自定义角色名字与图片
	
3,如果是记录之前盒的总价，可以选择自由模式，不受到总价限制，随意输入通行证价格
	
4,可以选择不同人数与精一二分开调整模式，只要选择4、5、6或是14人模式就可以兼容音律通行证
	
5,数据将会自动保存在浏览器中，一次调不完也没事，可以自由选择盒，一次同时调多盒！内置炒谷系统（bushi）点击保存可以生产当次调价后的折现图，清晰反应通行证价格变化~
	
6,可以一键复制调价到剪贴板，也可以一键生成Excel表格！表格自动记录价格、图片等信息方便分享（需要在浏览器中打开）

8.3 新增
市场模式：92 个盒的行情模板全内置——数字盒 1.0~54.0 全系列 + 音律联觉/嘉年华等 38 个主题盒，414 张干员头像也自带。选盒即出参考价，可一键「应用到当前盒」或「新建盒」，随时「还原默认价」
新手引导：第一次打开自动分步带一遍，工具栏随时可重看
撤销 / 重做：手滑不用怕
JSON 一键备份 / 恢复：价格历史、自定义图片全打包，发微信/网盘存着就稳
多标签页同步：开两个窗口一起调，实时同步
手机优化：移动浏览器打开几秒内可操作，蹲个团间隙就能调价
